# HVPC Resolve-MVSEP 0.3.0

## Русский

Добавлен мастер установки для Windows на русском и английском языках. В установщике, окнах программы и возле часов используется логотип HVPC.

1. Скачайте `HVPC-Resolve-MVSEP-v0.3.0-Windows.zip` и полностью распакуйте его.
2. Запустите `Install.exe`.
3. Выберите рабочую папку, вставьте API-токен MVSEP и нажмите **Установить**.

Мастер сам создаёт настройки и добавляет пункт запуска в DaVinci Resolve. При обновлении он сохраняет настройки, задачи и результаты, делает резервные копии заменяемых файлов и восстанавливает изменения при ошибке записи. Токен можно изменить повторным запуском мастера.

Режим установки определяется автоматически по выбранной папке. Для прежней установки кнопка называется **Обновить / настроить**; пустое поле токена сохраняет прежний токен.

В Resolve откройте **Preferences → System → General** и выберите **Local** в первой строке **External scripting using**. Если изменили значение, сохраните настройку и перезапустите Resolve. Эта инструкция показана на последнем экране мастера.

Требования: Windows, **DaVinci Resolve Studio 21.1+**, установленный в стандартную папку, аккаунт MVSEP и API-токен. Права администратора, отдельный Python и FFmpeg не требуются. В архиве исходников GitHub вместо `Install.exe` используйте `Install.cmd` — он соберёт то же окно средствами Windows.

Это независимая неофициальная интеграция. Собственный код распространяется по MIT; обработка и лимиты регулируются MVSEP. Подробнее — в README.

macOS запланирована отдельным этапом и пока не поддерживается.

## English

Added a Windows installation wizard in Russian and English. The installer, application windows and notification area now use the HVPC logo.

1. Download and fully extract `HVPC-Resolve-MVSEP-v0.3.0-Windows.zip`.
2. Run `Install.exe`.
3. Choose a working folder, paste your MVSEP API token and click **Install**.

The wizard creates settings and adds the DaVinci Resolve menu launcher. Updates keep settings, tasks and results, back up replaced files and roll back changes if a write fails. Run the wizard again to change your token.

The working folder determines the mode automatically. For an existing installation, the button reads **Update / configure**; leaving the token field empty keeps the saved token.

In Resolve, open **Preferences → System → General** and set the first field, **External scripting using**, to **Local**. If you changed the value, save and restart Resolve. The wizard shows this step on its final screen.

Requires Windows, **DaVinci Resolve Studio 21.1+** in its default installation folder, an MVSEP account and API token. No administrator rights, separate Python or FFmpeg are required. GitHub source ZIPs contain `Install.cmd` instead of `Install.exe`; it builds the same wizard using Windows components.

This is an independent, unofficial integration. The integration's own code is MIT licensed; processing and limits are governed by MVSEP. See the README for details.

macOS is planned as a separate development stage and is not supported yet.
