# HVPC Resolve-MVSEP

**Русский** · [English](README.en.md)

Разделяйте звук аудио- и видеофайлов и добавляйте результаты в DaVinci Resolve Studio — в медиатеку проекта или на отдельные аудиодорожки. Интерфейс доступен на русском и английском языках.

**Независимая неофициальная интеграция.** HVPC Resolve-MVSEP не связан с Blackmagic Design или оператором MVSEP и не одобрен ими. Названия DaVinci Resolve и MVSEP обозначают совместимость; права на них принадлежат соответствующим правообладателям.

## Возможности

- Каталог алгоритмов MVSEP: группы, поиск, выбор моделей и параметров.
- Интерфейс на русском и английском языках.
- Входные файлы WAV, MP3, FLAC и MP4 со звуком. Для MP4 звук извлекает сервер MVSEP.
- Фоновая обработка, состояние очереди и продолжение сохранённой задачи после сбоя.
- Импорт в Media Pool или на отдельные аудиодорожки с учётом положения и подрезки исходника.
- Свои наборы настроек и запоминание последнего выбора.

## Требования

- Windows и **DaVinci Resolve Studio 21.1 или новее**. Проверено на **21.1.0.17**; работа на других версиях не гарантируется.
- Аккаунт MVSEP, личный API-токен и подключение к интернету.
- Папка программы и папка результатов, доступные для записи.

Используется Python, встроенный в Resolve 21.1+. Отдельно устанавливать Python, FFmpeg или дополнительные библиотеки не требуется. Бесплатная редакция Resolve, macOS и Linux в этом выпуске не поддерживаются.

## Установка

1. Откройте [Releases](https://github.com/neiroivanych/hvpc-resolve-mvsep/releases), в разделе **Assets** скачайте архив **HVPC-Resolve-MVSEP-v0.3.0-Windows.zip** и полностью распакуйте его.
2. Дождитесь завершения разделений, закройте Resolve и окна HVPC Resolve-MVSEP, включая значок возле часов. Запустите **Install.exe** из распакованной папки.
3. Выберите **Рабочую папку**. Можно оставить предложенную или выбрать новую пустую папку — здесь будут программа, настройки и результаты.
4. Вставьте **API-токен MVSEP**. Если его нет, нажмите ссылку в мастере, войдите на [страницу API MVSEP](https://mvsep.com/ru/full_api) и скопируйте свой токен. Нажмите **Установить**.
5. В Resolve откройте **Preferences → System → General**. В первой строке **External scripting using** выберите **Local**, сохраните настройку и перезапустите Resolve. Если **Local** уже выбрано, ничего менять не нужно. Мастер напомнит об этом на последнем экране.

Готово: **Workspace → Scripts → HVPC Resolve-MVSEP**. Копировать файлы в служебные папки и редактировать JSON или Python вручную не нужно. Права администратора не требуются.

Мастер рассчитан на Resolve Studio 21.1+ в стандартной папке `Program Files\Blackmagic Design\DaVinci Resolve`. Установка выполняется для текущего пользователя Windows. Токен сохраняется локально в рабочей папке; пароль от аккаунта не нужен. Доступ к MVSEP проверяется при открытии окна разделения.

Режим определяется по рабочей папке автоматически: для новой папки кнопка называется **Установить**, для существующей установки — **Обновить / настроить**.

Для установки выбирайте архив с названием программы и пометкой **Windows**. Архивы **Source code** предназначены для разработчиков.

## Первое разделение

1. Откройте проект и таймлайн. Выделите **один клип на таймлайне**, а не в Media Pool. Для MP4 можно выделить связанную пару «видео + его звук» из одного файла или один её компонент.
2. Запустите **Workspace → Scripts → HVPC Resolve-MVSEP**. При необходимости выберите **RU** или **EN** в поле **Язык / Language**.
3. Выберите группу, алгоритм, параметры и формат результата. Укажите **Папку для результатов** или оставьте показанный путь.
4. При желании включите **Добавить в медиа проекта** либо **Добавить на дорожки (и в медиа)**. Это действие выполнится после скачивания. Галочки действуют только для текущего разделения.
5. Нажмите **Начать разделение**. После завершения откроется окно с результатами.

**В MVSEP отправляется весь исходный файл, включая части за границами подрезки на таймлайне.** Для MP4 загружается полный видеофайл. Исходный файл на диске не изменяется. Используйте материалы, которые вы вправе отправлять в сервис.

## Добавление в Resolve

| Кнопка | Результат |
| --- | --- |
| **В Media Pool** | Полные файлы добавляются в медиа проекта для дальнейшего монтажа. |
| **На новые дорожки** | Файлы добавляются в Media Pool и размещаются на отдельных аудиодорожках внизу исходного таймлайна. |
| **Открыть результат** | Открывается папка со скачанными файлами. |

Используется **текущее положение исходного клипа и его текущая подрезка слева и справа**. Исходник можно переместить по тому же таймлайну, в том числе на другую дорожку. Файлы результатов остаются полными: края новых клипов можно растянуть обратно в пределах доступного аудио.

Новые дорожки изначально **отключены кнопкой M**. Для прослушивания включите нужные дорожки результата и приглушите исходную. Скрипт не меняет громкость и состояние исходника. Номера добавленных дорожек показаны в окне результата; при необходимости прокрутите область аудиодорожек вниз.

Повторное нажатие проверяет уже добавленные файлы и не создаёт дубликаты. Если после импорта вы снова переместите или подрежете исходник, уже добавленные результаты автоматически за ним не перемещаются и не подрезаются.

Замена или удаление исходного клипа, изменение содержимого исходного файла, неподдерживаемая скорость и другие препятствия останавливают размещение с объяснением причины. Скачанные результаты можно использовать через Media Pool. Размещение поддерживает обычное моно/стерео аудио со скоростью 100%; эффекты и сложные изменения скорости исходного клипа не переносятся.

## Где сохраняются результаты

По умолчанию используется папка `output` внутри папки программы. Полный путь показан до запуска. Кнопка **Выбрать папку…** позволяет его изменить, а **Использовать для следующих разделений** — запомнить.

Для каждого исходника и каждой попытки создаётся отдельная папка. Файлы одной попытки имеют общий номер варианта. **Открыть результат** в окне готовой задачи ведёт прямо к её файлам.

## Работа в фоне и возврат к результату

Во время обработки **Свернуть в фон** или крестик скрывает окно, оставляя значок **HVPC Resolve-MVSEP** возле часов Windows. Значок может находиться в меню **↑**. Двойной щелчок возвращает окно. Повторный запуск скрипта из Resolve также показывает текущую задачу без новой отправки файла.

Если закрыть Resolve, обработка и скачивание продолжатся, пока работает фоновый процесс и компьютер включён. Импорт станет доступен после открытия исходного проекта и восстановления связи. При необходимости нажмите **Проверить связь**. После неудачного автоматического импорта используйте кнопки добавления вручную.

При завершении или ошибке полное окно возвращается. Если Windows не разрешает вывести его поверх других программ, проверьте мигающую кнопку на панели задач.

Если готовое окно уже закрыто, запустите скрипт и нажмите **Последний результат**. Откроется последний готовый результат текущего проекта без повторного разделения. Кнопки ручного добавления доступны и тогда, когда перед запуском вы не отмечали автоматический импорт.

Выключение компьютера или принудительное завершение фонового процесса прерывает локальную работу. Если в окне сохранённой задачи доступно **Продолжить задачу** или **Продолжить скачивание**, эта кнопка возобновляет её без повторной отправки исходника. При неопределённом результате загрузки сначала проверьте историю на MVSEP: сервер мог уже принять файл.

## Настройки, модели и лимиты

**Мои наборы настроек** позволяют сохранить алгоритм, его параметры и формат под своим именем. Кнопка **Настройки** в окне результата показывает настройки этой попытки.

**Сохранять последние настройки** восстанавливает алгоритм, его группу, параметры и формат при следующем открытии. **Только успешные** использует настройки завершившегося скачивания; **Все** — последний выбор, включая отменённое разделение. Если снять галочку, следующий запуск использует начальные настройки.

Пометка **[Premium]** относится к алгоритму или конкретному значению параметра. **Есть настройки Premium** означает, что у алгоритма есть такие значения, даже если настройки по умолчанию бесплатные. Перед отправкой проверьте доступ и баланс своего аккаунта MVSEP. Программа не предоставляет подписку или кредиты.

Баланс и число бесплатных разделений отображаются по данным MVSEP. Если данные недоступны, это не означает нулевой остаток. Каталог, доступность моделей и лимиты зависят от сервиса. Распознавание речи, синтез голоса и MIDI в этом окне разделения аудио пока не поддерживаются; подписка сама по себе не включает их поддержку в программе.

## Если возникла проблема

| Ситуация | Что сделать |
| --- | --- |
| Пункта меню нет | Закройте Resolve, повторно запустите мастер и выберите свою рабочую папку. Затем откройте Resolve. |
| Программа не найдена | Повторно запустите мастер и укажите существующую рабочую папку. Не перемещайте её после установки. |
| Вместо настроек открылся отчёт о клипе | В `settings.json` установите `"action": "separate"` или используйте свежий `settings.example.json` как основу. |
| Не выбран клип | Выделите один клип на таймлайне; для MP4 допустима связанная пара видео и его звука. |
| Ошибка API-токена | Закройте окна программы и Resolve, запустите мастер и вставьте действующий токен в прежней рабочей папке. |
| Нет подключения к Resolve | Откройте исходный проект, проверьте **External scripting using → Local**, нажмите **Проверить связь**. |
| Размещение на дорожках отклонено | Прочитайте причину в выделенной области окна. Откройте нужный таймлайн, восстановите исходник либо используйте **В Media Pool**. |
| Дорожки добавлены, но звука нет | Найдите указанные номера дорожек внизу таймлайна и включите их кнопкой **M**. |
| Сбой скачивания или тайм-аут | Используйте **Продолжить скачивание / Продолжить задачу**, если кнопка доступна. |

Если проблема повторяется, создайте обращение во вкладке **Issues** этого репозитория GitHub. Укажите версии Windows и Resolve, версию или дату скачивания программы, формат исходника, шаги и текст ошибки. Скриншот полезен, если на нём нет личных данных.

Не прикладывайте API-токен, папку `config` или весь проект. Перед отправкой журнала из `logs` либо папки задачи проверьте его: он может содержать имена файлов, пути и название проекта.

## Обновление

Дождитесь завершения фоновых задач и закройте Resolve и окна программы. Распакуйте новый архив в отдельную папку и запустите **Install.exe**. В **Рабочей папке** выберите прежнюю установку — обычно мастер найдёт её сам. Оставьте поле токена пустым, чтобы сохранить прежний, и нажмите **Обновить / настроить**.

Настройки, задачи и результаты сохраняются. Копии заменяемых файлов находятся в `config\installer-backups` внутри рабочей папки. Если запись прервётся, мастер попытается восстановить прежние файлы и сообщит результат.

Для смены токена используйте тот же мастер и прежнюю рабочую папку. Созданный мастером пункт меню всегда открывает выбранную папку, даже если раньше была задана переменная `RESOLVE_MVSEP_HOME`.
